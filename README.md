# 📽️ PinyinGo Guru - Portal Slaid Pengajaran Bilik Darjah (ELM 4322)

Aplikasi slaid pembentangan interaktif untuk guru Bahasa Mandarin Kolej Vokasional, direka khas untuk tayangan projektor, *smartboard*, dan skrin TV bilik darjah.

---

## 🌟 Ciri-Ciri Utama Slaid Guru

1. **Tipografi Gergasi & Jelas:** Huruf Hanzi tebal dan Ruby Pinyin berwarna terang, mudah dibaca dari belakang kelas.
2. **Audio Penutur Jati Segera:** Tekan butang 🔊 pada mana-mana perkataan atau baris dialog untuk sebutan penutur jati standard (*zh-CN*).
3. **Kawalan Papan Kekunci Pantas:**
   - Kekunci `➔` / `Spacebar`: Slaid Seterusnya
   - Kekunci `⬅️`: Slaid Terdahulu
   - Kekunci `F`: Mod Skrin Penuh (*Fullscreen*)
   - Kekunci `H`: Kembali ke Laman Utama
4. **Aktiviti Interaktif Kelas:** Soalan kuiz spontan dengan butang *"Dedahkan Jawapan"* untuk penglibatan aktif murid di dalam kelas.
5. **Watermark Rasmi (Bottom Left):** `Hajar Nur Atiqah Binti Mohd Adam`.
